# Patch Pass
Vanilla embroidery notebook on localStorage. No backend or runtime dependencies.

`npm start` (Python 3), open http://localhost:4173. `npm test` runs the domain suite.

`index.html` shell; `src/` = `app.js` DOM/storage, pure `domain.js`, SVG `art.js`, `style.css`; `tests/` = `node --test`; `types.d.ts` = interfaces.

Five editable samples; CRUD, search, status filters, sorting, session theme. Serve over HTTP.
